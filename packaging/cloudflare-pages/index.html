Что внутри

🎮

Запуск в один клик

Minecraft 1.16.5 + OptiFine HD U G8. Авто-установка Java 8 и всех зависимостей.

⚡

Ultra FPS-профиль

Render distance = 4, без облаков, без AO, без частиц. G1GC + Aikar JVM-флаги. Авто-Xmx по системной RAM.

🗂

Мульти-инстансы

Отдельный .minecraft на каждый профиль: vanilla, OptiFine, Forge, тестовый.

🎯

Любая версия MC

1.8.9, 1.12.2, 1.16.5, 1.18.2, 1.19.4, 1.20.1 через Mojang piston-meta.

🔍

Modrinth-браузер

Поиск и установка модов в один клик прямо из лаунчера.

🛰

Браузер серверов

Нативный MC SLP-протокол. Пинг, MOTD, онлайн.

👥

Друзья + чат

WebSocket-чат лаунчера, статус друзей, приглашения.

💥

Анализатор крашей

Парсит crash-reports и сразу подсказывает, что чинить.

💾

Бэкапы миров

Снапшот saves/ в zip + облачный бэкап через S3/R2.

🎨

Темы

Светлая / тёмная / системная + кастомный hex-акцент.

🔔

Авто-апдейт

Скачивает фоном новую версию, ставит при выходе из игры.

🛡

Без рекламы и трекинга

Open-source. Телеметрия выключена по умолчанию.
